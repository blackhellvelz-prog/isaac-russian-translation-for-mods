# Credits

Other mods this mod works with. Their files are not changed and not included here: our code reads their data or wraps their functions at runtime, and does nothing when the mod is not installed.

| Mod | Author | What our code does | Where |
|---|---|---|---|
| [Mod Translator](https://steamcommunity.com/sharedfiles/filedetails/?id=2881743468) | Goganidze | Russian names go through its translation API (ItemTranslate); its Cyrillic fonts are used | `ru_items.lua, ru_font.lua` |
| [External Item Descriptions](https://steamcommunity.com/sharedfiles/filedetails/?id=836319872) | Wofsauge | Russian descriptions are added to its description tables | `ru_items.lua, ru/eid_*.lua` |
| [Passive Skill Trees (Rep+)](https://steamcommunity.com/sharedfiles/filedetails/?id=3305869734) | Ab Aeterno | PST:getLocalized is wrapped to return Russian strings; help pages get Russian pictures | `ru_pst.lua, ru_images.lua` |
| [Encyclopedia - An In-Game Wiki!](https://steamcommunity.com/sharedfiles/filedetails/?id=2376005362) | AgentCucco | DSS menu strings and article texts are translated before they are drawn | `ru_dss.lua, ru_ency.lua` |
| [Mod Config Menu Pure](https://steamcommunity.com/sharedfiles/filedetails/?id=3680349610) | t33ot | category and option texts are translated | `ru_mcm.lua` |
| [Fiend Folio: Reloaded](https://steamcommunity.com/sharedfiles/filedetails/?id=3778123093) | Erfly | fortunes and pop-up texts are translated on output | `ru_fortunes.lua, ru_popup.lua` |
| [REPENTOGON: Isaac Script Extender](https://steamcommunity.com/sharedfiles/filedetails/?id=3127536138) | jerb | its stats page strings are translated | `ru_rgon.lua` |
| [IPECAC Community Mod](https://steamcommunity.com/sharedfiles/filedetails/?id=1925867065) | pedroff_1 | item names and descriptions | `ru/ipecac.lua, ru/eid_ipecac.lua` |
| [Lost and Forgotten](https://steamcommunity.com/sharedfiles/filedetails/?id=3440586497) | ENFOR | item names and descriptions | `ru/lostandforgotten.lua, ru/eid_lostandforgotten.lua` |
| [Furtherance](https://steamcommunity.com/sharedfiles/filedetails/?id=3513706025) | Benny | item names and descriptions | `ru/furtherance.lua, ru/eid_furtherance.lua` |
| [Heaven's Call](https://steamcommunity.com/sharedfiles/filedetails/?id=3503885496) | Ultrinik | item names and descriptions | `ru/heavenscall.lua` |

Library: [REPENTOGON](https://steamcommunity.com/sharedfiles/filedetails/?id=3127536138) by jerb and the REPENTOGON team — required.

Thanks to the authors of these mods and to the whole Isaac modding community.
