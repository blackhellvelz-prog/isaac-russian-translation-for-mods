# Russian Translation for Mods

The Binding of Isaac: Repentance+ mod (REPENTOGON). Author: blackhellvelz.

English · [Русский](#русский)

A Russian translation for popular mods, on top of [Mod Translator](https://steamcommunity.com/sharedfiles/filedetails/?id=2881743468): it covers what Mod Translator doesn't. Works only when the game language is Russian — with English the game and the mods stay as they are.

### What is translated
- **Items, trinkets, cards, pills** — names, pickup texts and EID descriptions (about 900 names and 2000 descriptions): Fiend Folio, IPECAC, Lost and Forgotten, Furtherance, Heaven's Call, Magic-Expanded, Flipped Runes and smaller mods; golden trinket and Mom's Box effects, birthrights, Book of Virtues wisps.
- **Passive Skill Trees** — every node, tree names, help pages (with Russian pictures), the level bar.
- **Dead Sea Scrolls menus** of all mods (settings, changelog headers, tips), **Mod Config Menu** sections, **Encyclopedia** articles (the main sections of thousands of entries).
- **Fiend Folio fortunes** (about 6700), pop-up texts of mods, built-in mod labels, the REPENTOGON stats page.
- **Pictures**: the official Russian pictures of the game (boss versus screen, giant book, controls on the floor) and Russian versions of mod pictures (controls of modded characters, PST help) — swapped in only with the Russian language.


### Requirements

- [Mod Translator](https://steamcommunity.com/sharedfiles/filedetails/?id=2881743468) (its Cyrillic fonts)

## Install

Subscribe on Steam Workshop — that's all. To install by hand, copy this folder into `The Binding of Isaac Rebirth/mods/`.

## Repository

This repository is the mod folder itself: `main.lua` is the entry point, the other `.lua` files are its modules, `resources/` — pictures, `metadata.xml` — the Workshop page. Pictures that belong to the game or to other mods are not stored here. Other mods this one works with — [CREDITS.md](CREDITS.md). Code license — [LICENSE](LICENSE) (MIT).

## Русский

Русский перевод популярных модов поверх [Mod Translator](https://steamcommunity.com/sharedfiles/filedetails/?id=2881743468): здесь то, чего в нём нет. Работает только при русском языке игры — с английским игра и моды остаются как есть.

### Что переведено
- **Предметы, брелоки, карты, пилюли** — названия, надписи при подборе и описания EID (около 900 названий и 2000 описаний): Fiend Folio, IPECAC, Lost and Forgotten, Furtherance, Heaven's Call, Magic-Expanded, Flipped Runes и небольшие моды; эффекты золотых брелоков и Маминой шкатулки, права первородства, огоньки Книги добродетелей.
- **Passive Skill Trees** — все узлы, названия деревьев, справка (с русскими картинками), полоса уровня.
- **Меню Dead Sea Scrolls** всех модов (настройки, заголовки журналов, подсказки), разделы **Mod Config Menu**, статьи **Encyclopedia** (главные разделы тысяч статей).
- **Предсказания Fiend Folio** (около 6700), всплывающие надписи модов, вшитые надписи модов, страница статистики REPENTOGON.
- **Картинки**: официальные русские картинки игры (экран «против босса», большая книга, управление на полу) и русские версии картинок модов (управление у персонажей модов, справка PST) — подставляются только при русском языке.
